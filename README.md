# Sean Dinwiddie's Orbital Registry

[portfolio.sdin.dev](https://portfolio.sdin.dev) is an interactive registry
for Sean Dinwiddie's work, public missions, and experiments. It presents the
system as an original science-fiction mission interface: cinematic, responsive,
and always grounded in useful content.

## Explore

* **Ingress** — enter through the live signal display, primary destinations,
  phone QR, and theme-aware orbital scene.
* **Nexus** — monitor Sean's public network presences, aggregate audience and
  discovery signals, growth baselines, and registry destinations.
* **Dossier** — read the registry's capabilities, intent, and operating protocols.
* **Missions** — browse public repositories, custodians, dialects, contributions,
  recent activity, and commits.
* **Telemetry** — see whether live records are current, partial, stale, or
  temporarily unreachable, along with the active visual settings.

Unknown signals keep you inside the Registry and provide a clear route to Ingress.

## Shape the experience

Use the theme control to move among **Ayu Dark**, **Ayu Light**, **Ayu Mirage**,
**Dracula**, **SynthWave '84**, and the original deep-red **Ruby Crystal**.
The contribution calendar, controls, surfaces, labels, and orbital visuals
change with the selected theme. Your built-in theme choice is remembered
between visits.

**Download Theme** gives you the current colors as editable CSS. **Load Custom
Theme** previews your own compatible CSS; leaving the custom theme returns to
the built-in catalog.

The space-opera scene and transitions are always active. Controls provide
theme-aware visual feedback and short sci-fi hover/press sounds. Your device's
reduced-motion preference still takes priority for motion accessibility.

Open **Archive Control** for a keyboard-friendly command deck. Start with
`help`, then explore identity, repositories, languages, activity, or change the
theme or navigate between workspaces from the prompt. Escape or the visible
close control returns you to the workspace.

## Access and data

The Registry is designed for keyboard navigation, visible focus, browser zoom,
small screens, reduced motion, forced colors, and readable contrast across every
built-in theme. Motion and decoration are never required to reach the content.

Registry copy and mission records come from the live sdin.dev service. Public
GitHub totals and activity naturally change over time. If part of the service is
slow or unavailable, the interface reports that state instead of presenting an
empty frame as current data. The selected theme is saved as a local visitor
preference.

The Nexus Observatory is intentionally public. It shows bounded aggregate
Analytics, Search Console, GitHub, and channel-reachability evidence—including
honest zero baselines and growth over time—without exposing visitor identities,
raw searches, path-level records, countries, credentials, or private property
configuration.
